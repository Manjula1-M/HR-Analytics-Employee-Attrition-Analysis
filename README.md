# HR-Analytics-Employee-Attrition-Analysis

1. Project Overview

This project focuses on analyzing employee data to understand employee attrition and identify factors affecting employee retention using SQL Server.

2. Objectives

- Analyze overall employee attrition.
- Identify department-wise attrition.
- Analyze job role-wise attrition.
- Understand the relationship between salary and attrition.
- Analyze overtime and employee satisfaction.
- Provide business recommendations to improve employee retention.

3. Tools Used

- Microsoft SQL Server
- SQL

4. Project Process

1. Data Exploration
2. Data Cleaning
3. Business Analysis
4. Business Insights
5. Business Recommendations

5. Key Business Questions

- Which department has the highest attrition?
- Which job role has the highest attrition?
- Does overtime affect employee attrition?
- Are lower-paid employees more likely to leave?
- How can the company improve employee retention?

6. Business Recommendations

- Review employee salary structures.
- Reduce unnecessary overtime.
- Improve work-life balance.
- Provide career growth opportunities.
- Improve employee satisfaction.

7. Conclusion

This project helps understand employee attrition patterns and provides data-driven recommendations to support better HR decision-making.
